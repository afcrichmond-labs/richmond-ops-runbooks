# Employee Onboarding - Access Provisioning

**Owner:** Leslie Higgins (IT Admin)
**Last Updated:** 2025-12-15

## When to Use
When a new employee joins and needs system access.

## Prerequisites
- HR has created the employee record
- Manager has approved the access level

## Steps
1. Create SSO account via Okta admin panel
2. Add to GitHub org (afcrichmond-labs) with appropriate team
3. Create Linear account and add to workspace
4. Add to Notion workspace
5. Add to Slack workspace and relevant channels
6. If engineering: provision AWS IAM user with role-based policy
7. Send welcome email with setup instructions
8. Schedule 48h access verification check
